# e-ISMS — Laravel local pilot

Laravel 13 application for internal accounts and controlled documents. Source of truth for scope/assumptions: ../docs/phase-1-design.md. Setup: ../docs/laragon-setup.md. Verification: ../docs/review/laravel/verification.md.

Run MySQL in Laragon, build assets with npm ci / npm run build, then run ../scripts/Start-ISMS.ps1 from the repository root. Document root: application/public. Demo credentials are local only and excluded from Git.

Risk, actions and SoA are still review mockups under ../mockup. This pilot is not an approved operational ISMS or a compliance certificate.
